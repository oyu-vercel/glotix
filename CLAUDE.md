# Glotix

Italian language-learning app for Russian-speaking learners (currently: Italian A2 vocabulary).

## Commands

- Start dev server (web): `npm --prefix web start` → http://localhost:4200
- Build (web): `npm --prefix web run build`
- Test (web): `npm --prefix web test`
- Rebuild per-story JSONs after editing a story or `vocabulary.json`: `npm --prefix web run build:stories`
- Rebuild per-drill JSONs after editing a drill CSV or `vocabulary.json`: `npm --prefix web run build:drills`
- Start API (currently paused): `npm --prefix api run start:dev`

## Stack

- **Frontend** — Angular 21 standalone + Angular Material 21 + Signals, in `web/`. TypeScript strict mode with `strictTemplates: true`. **Visual system: Soft Warm Modern** — terracotta `#C95D3A` primary + sage `#7E9173` tertiary on cream `#F7F1E5`, Inter body with Fraunces italic accents, light color scheme locked. See [docs/visual-redesign.md](docs/visual-redesign.md).
- **Backend** — NestJS 11 + TypeORM + better-sqlite3 (dev) / Postgres (prod), scaffolded in `api/`. Currently paused — nothing in the Angular app calls it.
- **Static data** — Files under `web/public/` are served at the URL root (e.g. `web/public/assets/x.json` → `/assets/x.json`).

## Conventions

- Standalone Angular components only — no NgModules.
- Component files use short names without the `.component` suffix: `summary.ts`, not `summary.component.ts`.
- Code style: Prettier (`printWidth: 100`, `singleQuote: true`, Angular parser for `.html`). Config at [web/.prettierrc](web/.prettierrc).
- Color scheme is locked to **light** at `web/src/styles.scss:26`. Do not switch to `dark` or `light dark`, and do not add `prefers-color-scheme: dark` overrides.
- Vocabulary source of truth: `web/public/assets/vocabulary.json` (hand-edited). Served directly to the Angular app at `/assets/vocabulary.json` by the existing `public/` asset glob — no build step.
- Stories source of truth: `.txt` files under `docs/stories/<folder>/` (one folder per story). The Angular app reads `web/public/assets/stories-index.json` and `web/public/assets/stories/<slug>.json`, generated by `web/scripts/build-stories.mjs` (walks subfolders recursively). Each per-story JSON stores `vocabulary` as `Record<categoryKey, n[]>` references into `vocabulary.json`; the Angular vocabulary service resolves them at runtime. Story tokens not found in `vocabulary.json` are silently excluded — add the word to `vocabulary.json` to include it.
- Lessons source of truth: hand-written `web/public/assets/lessons/<slug>.json` plus `lessons-index.json`. No build step — unlike stories and drills, lesson JSON is authored directly. Words are stored inline (not as `vocabulary.json` refs); `pronunciation` and `examples` are looked up from `vocabulary.json` at runtime by `category` + `italian`. Raw transcripts live at `docs/italian/italian-<n>.txt` — run the `add-lesson` skill to onboard one.
- Drills source of truth: one `*.csv` per folder under `docs/drills/<folder>/` (5-column format — see [docs/drills.md](docs/drills.md)). The Angular app reads `web/public/assets/drills-index.json` and `web/public/assets/drills/<slug>.json`, generated by `web/scripts/build-drills.mjs`. Drills with any word missing from `vocabulary.json` are skipped at build time — run the `add-drill` skill to ingest a new drill.
